# 钻石版门店分布地图

基于高德地图 AMap JS API 的交互式地图，展示西宁市 24 家电竞门店/网咖/电竞酒店位置。

## 🚀 开箱即用

**API Key 已内嵌，双击 `index.html` 直接在浏览器打开即可！**

## ✨ 功能

- 🗺️ **高德地图** —— 矢量地图（浅色风格）+ 卫星图可切换
- 📍 **24 个标注点** —— 每家门店编号标记，按区域颜色区分
- 🔍 **可放大查看** —— 鼠标滚轮缩放、拖拽平移、双击放大
- 🔎 **搜索 + 过滤** —— 按店名/地址搜索；按区域 Tab 过滤
- 💫 **联动交互** —— 点击侧边栏列表 → 自动定位并弹窗；点击标记 → 高亮列表
- 🌐 **导航跳转** —— 弹窗内提供「高德查看」「搜索详情」按钮
- 🌞 **明亮风格** —— 清爽白色 UI

## 操作说明

| 操作 | 效果 |
|------|------|
| 滚轮 / 双击 | 放大 / 缩小 |
| 拖拽地图 | 平移 |
| 点击标记 | 显示门店信息 + 高亮列表 |
| 点击列表项 | 自动定位到标记 + 弹窗 |
| 顶部搜索框 | 按门店名/地址过滤 |
| 区域 Tab | 按城中/城西/城东/城北过滤 |
| 弹窗按钮 | 在高德地图中查看该位置或搜索详情 |
